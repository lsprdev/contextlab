# Regras de frete

O serviço atende as zonas local, regional e nacional. Cada zona possui uma
tarifa básica. O primeiro quilograma está incluído nessa tarifa; cada
quilograma adicional custa três unidades monetárias. Pesos fracionários são
permitidos, com cobrança proporcional do excesso.

Clientes VIP recebem vinte por cento de desconto quando o pacote pesa até
cinco quilogramas, inclusive. O resultado é arredondado para duas casas
decimais. Peso não positivo e zona não atendida são entradas inválidas.

Este é um domínio fictício para exercitar o instrumento de pesquisa.
