# Projetos para aprender e usar o ContextLab

Cada pasta contém uma aplicação e seu `contextlab.json`. Comece por
[cambio](cambio/README.md) e siga o [primeiro experimento](../contextlab/docs/PRIMEIRO_PROJETO.md).

Depois, use o [OrçaAPI](orcamentos/README.md): API de orçamentos com FastAPI e
SQLite, incluindo uma função com dependências locais e um exercício HTTP.

Ambos são autorais e didáticos. Não substituem Fava, bump-my-version, python-dotenv ou
python-stdnum na amostra do TCC. Os resultados locais ficam em `*/runs/`, fora do Git.
